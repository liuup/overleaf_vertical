# Overleaf Vertical
🔥强制 Overleaf 编辑器和PDF预览从上到下显示，而不是并排显示

👀亮点:

1. Overleaf平台的开源扩展
2. 更有效地利用屏幕空间, 一边写论文一边查文献。
3. 只需一个简单的按钮即可轻松切换 Overleaf 布局
